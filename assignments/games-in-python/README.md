
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Construa o clássico jogo de adivinhar palavras em Python. Pratique manipulação de strings, loops, condicionais, entrada de dados e seleção aleatória.

## 📝 Tarefas

### 🛠️ Implementar a palavra oculta e o progresso

#### Descrição
Crie a estrutura inicial do jogo: selecione uma palavra aleatoriamente de uma lista predefinida e permita que o jogador tente adivinhar suas letras.

#### Requisitos
O programa concluído deve:

- Selecionar uma palavra aleatoriamente de uma lista predefinida.
- Mostrar as letras ainda não adivinhadas como espaços em branco, por exemplo, `_ _ _`.
- Revelar no progresso todas as ocorrências de uma letra quando o palpite estiver correto.


### 🛠️ Controlar tentativas e encerrar a partida

#### Descrição
Complete o fluxo do jogo contabilizando palpites incorretos e encerrando a partida quando a palavra for adivinhada ou as tentativas acabarem.

#### Requisitos
O programa concluído deve:

- Rastrear e exibir as tentativas incorretas restantes.
- Continuar solicitando palpites enquanto a palavra não for adivinhada e ainda houver tentativas.
- Exibir uma mensagem de vitória quando o jogador adivinhar a palavra.
- Exibir uma mensagem de derrota quando as tentativas acabarem e revelar a palavra secreta.
